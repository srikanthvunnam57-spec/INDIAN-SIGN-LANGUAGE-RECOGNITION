## Indian Sign Language Recognition

## 1. Project Overview
Indian Sign Language Recognition is a Machine Learning-based image classification project designed to identify hand gestures representing Indian Sign Language (ISL). The system processes hand gesture images and predicts their corresponding sign categories.

The main aim is to explore image processing and Machine Learning techniques to support accessible communication.

## 2. Project Objectives
- Understand and explore the Indian Sign Language image dataset.
- Perform image preprocessing and feature extraction.
- Build multiple classification models.
- Evaluate model performance using appropriate metrics.
- Compare models and identify the best-performing algorithm.
- Develop a model capable of predicting sign categories from input images.

## 3. Dataset Description
The project uses an Indian Sign Language image dataset containing hand gesture images organized into different sign categories.

Each category represents a particular hand gesture and serves as a target class for classification.

## 4. Data Preprocessing
The following preprocessing operations are performed:
- Dataset loading and exploration.
- Image resizing and conversion.
- Label encoding.
- Training, validation, and testing split.
- HOG (Histogram of Oriented Gradients) feature extraction for classical Machine Learning models.

## 5. Machine Learning Models
The following classification algorithms are considered:

1. Support Vector Machine (SVM)
2. Logistic Regression
3. Random Forest Classifier
4. K-Nearest Neighbors (KNN)
5. Convolutional Neural Network (CNN).

## 6. Model Evaluation
Model performance is evaluated using:
- Accuracy
- Precision
- Recall
- Macro F1-score
- Weighted F1-score
- Classification Report
- Confusion Matrix

## 7. Model Comparison and Hyperparameter Tuning
The implemented models are compared using their evaluation metrics to identify the most suitable classifier. Hyperparameter tuning is performed where applicable to optimize model performance.
